## How to Read This Table

Each row is one ethics document. Columns:

- **#** — sequential number within that division
- **ID** — registry identifier (ISIC-{Section}{Div}-{Seq})
- **Org (Abbrev)** — organization abbreviation (full name in the source JSON)
- **Document Title** — clickable link to the source document (titles truncated at 60 chars if long)
- **Type** — document type abbreviation (see legend below)
- **Enf** — enforcement level abbreviation (see legend below)
- **Scope** — geographic scope
- **Year** — year published (— = undated)

### Enf (Enforcement) Abbreviations

| Abbrev | Meaning |
|--------|---------|
| `Stat` | Statutory / legally binding / mandatory / quasi-statutory / treaty obligation — carries legal force |
| `Bind` | Self-regulatory binding — enforced through membership, certification, credentialing, or third-party audit; no state legal force but contractual/associational obligation |
| `Asp` | Self-regulatory aspirational / advisory / soft law — recommended norms, no enforcement mechanism |
| `Vol` | Voluntary — open adoption, no binding commitment required |
| `Intl` | International model / UN-endorsed voluntary instrument — designed for broad voluntary adoption across states or sectors |
