### Notes
- **Strongest enforcement entries**: FIFA Code of Ethics (independent adjudicatory chamber), IOC Code of Ethics (Ethics Commission with sanction power), WADA Code (750+ organizations bound, athlete bans), UK Gambling Commission LCCP (statutory with licence revocation), CILIP (chartered professional body).
- **Most internationally comprehensive**: ICOM Code of Ethics for Museums (mandatory for members worldwide, 38 language translations), IFLA Code of Ethics (model for 60+ national associations), ICA Code of Ethics (24 languages), ICF Code of Ethics (globally recognized coaching credential).
- **Division 90 (Arts)**: Professional codes are weaker here — DGA and WGA operate through collective bargaining rather than traditional ethics codes; no comparable code found for visual artists (CAA does not publish a standalone ethics code for individual artists).
- **Division 92 (Gambling)**: Notable contrast between statutory enforcement (UK Gambling Commission) and industry self-regulation (AGA); NCPG focuses on treatment professionals and public standards rather than a code for gambling workers per se.
- **Notable gaps**: No specific ethics code found for live performing arts (Actors' Equity Association focuses on labor conditions, not ethics per se); no dedicated code for sports agents beyond FIFA's Intermediary Regulations.
