# Section T — Activities of Households as Employers
## Research Notes (ISIC Rev. 4, Divisions 97–98)

**Date:** 2026-03-21
**Researcher:** Claude Code (agent)
**Wave:** 4

---

## Overview

Section T covers households employing domestic staff (Division 97) and households producing goods or services for their own use (Division 98). By definition, these are private household arrangements, not organized professional sectors. As predicted in prior wave planning, this section yields very few professional ethics codes. The search confirmed this.

The key finding: some intermediary organizations (au pair agencies, domestic worker advocacy groups) have codes, but these apply to the *placement agencies* (which belong to Division 78 — Employment Activities) or advocacy organizations (which belong to Division 94 — Membership Organizations), not to the individual households-as-employers that Division 97 describes.

## Division 97 — Activities of Households as Employers of Domestic Personnel

### What was searched:
1. NDWA (National Domestic Workers Alliance) — code of conduct for advocacy organization
2. IAPA (International Au Pair Association) — code of conduct for placement agencies
3. ILO Convention C189 — international labor standard for domestic workers
4. Au pair host family guides and codes
5. Domestic worker standards organizations

### Findings:

#### IAPA — International Au Pair Association
- **Document:** Code of Conduct for Au Pair Organisations
- **URL:** https://iapa.org/about/code-of-conduct/
- **Notes:** This code governs *au pair placement organizations* (agencies), not individual households-as-employers. IAPA sets standards for selection of au pairs and families, ethical treatment, and professional conduct. Relevant to the household employment sector but applies to the intermediary agencies (Division 78) rather than to households themselves (Division 97).
- **Scope:** International
- **ISIC classification note:** The IAPA code most properly belongs to Division 78 (Employment Activities / placement agencies). Included here as the closest relevant code touching the household employment ecosystem.

#### ILO Convention C189 — Domestic Workers Convention, 2011
- **Document:** Convention on Decent Work for Domestic Workers (C189)
- **URL:** https://normlex.ilo.org/dyn/nrmlx_en/f?p=NORMLEXPUB:12100:0::NO::p12100_ILO_CODE:C189
- **Notes:** International labor convention establishing minimum standards for domestic workers: rest periods, minimum wage, protection against abuse, minimum age. This is a *regulatory/treaty framework*, not a professional code of ethics for a professional body. Governs the relationship between domestic workers and their household employers but is an ILO instrument, not an association ethics code.
- **Status:** Treaty/convention — included as the best available normative framework for this sector; not a professional association code

#### NDWA — National Domestic Workers Alliance
- **Document:** No formal code of ethics found
- **URL:** https://www.domesticworkers.org/
- **Notes:** NDWA is an advocacy organization for domestic workers (2.2 million nannies, housecleaners, home care workers). While NDWA has governance documents (conflict-of-interest policy, board member agreements), it does not publish a professional code of ethics for domestic workers or household employers. NDWA is classified in Division 94 (Membership/Advocacy Organizations), not Division 97.
- **Status:** No relevant code found; organization misclassified relative to Div. 97

### Key gap analysis:

There is a structural gap in Section T: the employing party (private households) is not organized as a profession and has no professional association. Ethics governance for this sector comes from:
1. **Labor law** (minimum wage, working hours, anti-discrimination)
2. **International conventions** (ILO C189)
3. **Placement agency codes** (IAPA — applies to agencies, not households)
4. **Individual nanny/au pair contracts** (private agreements)

No professional association has issued a code of ethics for "household employers" as a class. This is expected: employers of domestic workers are private individuals acting in a personal capacity, not professionals in an organized field.

## Division 98 — Undifferentiated Goods- and Services-Producing Activities of Private Households for Own Use

### What was searched:
- Homesteading organizations, subsistence activities, self-sufficient households
- Home crafting and maker ethics codes

### Findings:
Nothing found. This division describes households producing for their own consumption (subsistence activities), which have no professional organization and no associated ethics code. This is definitionally not a profession.
